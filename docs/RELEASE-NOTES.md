# mycodebox release notes

The release note of this repo (owner 2026-11-13). Every merged code change (not docs-only) adds one entry at the top of
`## Unreleased`; the done-check reads the merged diff for this file (REFERENCE "Closing review"). Entry form: one line,
what changed and why it matters, ending with `· area: <area>`.

## Unreleased

- **Commands group and fold in the reader when the session file is not found (owner 2026-11-23)** — with no session file the reader falls back to the pane, which writes tool lines as `Bash(cd …` (often cut before the closing paren); only the `Bash cd …` form of the session file was grouped, so each command stood alone. Both forms are now one collapsed group per run of consecutive commands (`public/tool-lines.js`) · area: dashboard

- **Context summaries and long AI messages fold in the reader (owner 2026-11-23)** — Claude Code's "This session is being continued from a previous conversation…" summary was shown blue, as if the owner had typed it. It is now an AI prompt (gray, "AI · context summary"), and any AI prompt over 4 lines or 400 characters (summary, manager message, check) starts folded to its first line; a click opens it and the reader keeps it open across repaints (`public/prompt-sig.js` `foldsPrompt`) · area: dashboard

- **Web links in the reader open on a tap (owner 2026-11-23)** — the phone app shows the reader, and a plain `https://…` URL in an answer was plain text there (only the terminal linked it). URLs in the reader are now links that open in a new tab; sentence punctuation stays outside the link and a path inside a URL is not also a file link (`public/file-links.js` `linkUrls`) · area: dashboard

- **Attaching .md and .txt files from a Mac works (owner 2026-11-23)** — a Mac browser often gives a .md / .txt no type, so the upload went out as `application/octet-stream` and was refused, and .txt was refused outright. The attach button, drop, paste and the new-session dialog now take images and text files (.md, .txt, .csv, .json, .yaml, .log) by extension, and the saved copy keeps its name (`<time>-<id>-ai_bot_story_ep01_final_script.md`), so the agent sees what it is (`upload-kind.js`, `public/upload.js` `uploadType`) · area: dashboard

- **Files an agent names open in a side panel (owner 2026-11-23)** — like Cursor / Claude Code: a path in the reader (`docs/X.md`, `server.js:120`, `INVENTORY.md`) or the terminal opens a panel on the right (full screen on a phone) with the file: markdown rendered, code with line numbers and the named lines marked. Buttons: copy the content, copy the path, full screen, open in a new tab (`/view.html`), close (Esc / back). Links inside the file open beside it. `GET /api/file` (`file-view.js`) serves text files only, at most 1 MB, under home or the scratchpads, never a dot folder (except Claude skills, agents, memory and CLAUDE.md), a binary or a secret-looking name · area: dashboard

- **Picture, video and page paths are clickable in the terminal too (owner 2026-11-23)** — on the phone the card shows the terminal, where only URLs were links, so `[file] out/ep01.mp4` could not be opened. A picture / video / page / PDF path in the terminal now opens in a new tab, and the reader also shows relative paths (`out/a.png`) inline. A relative path is looked up in the session's folder by `/files-in/<session>/<path>` (`findInFolder`: `<cwd>/<path>`, else a bounded search; dot folders skipped), which redirects to the checked `/files/` route · area: dashboard

- **Fingerprint gate reads the real retest report verdict (owner 2026-11-22)** — the lane required **PASS** on the first non-empty line, but `fingerprint_retest.py` reports start with a title (or frontmatter) and carry the verdict on line 3, so a passing retest was returned. The verdict is now the first line within the first 15 lines containing **PASS** or **FAIL**; FAIL first or none still blocks · area: integration lane

- **Park / move on the owner's word kills the session's own running work (owner 2026-11-22)** — the dashboard Park button, the account switch and `claude-account move` used to answer "Can't park …: busy, background job, running child process". They now end the turn, stop only the descendants of that session's Claude pane (SIGTERM, SIGKILL after 4 s) and park / resume anyway; the toast and CLI name the killed pids and the leases still held (not released). `--safe` and the automatic limit swap keep the refusal · area: sessions

- **Fingerprint algorithm merge gate (owner 2026-11-22)** — in the virtualpytest lane a change to the paths listed in `scripts/review/fingerprint_algorithm_paths.txt` is returned unless a manager approved it (`--approved-by manager`) and a no-regression retest report is in the diff (`docs/agent/navigation/retest-reports/`) or named in `--note`; docs in those folders pass · area: integration lane

- **Owner-ask auto-resolve reads the STATUS word only (bug-71b3ff6a)** — a stop with no STATUS line (plain text, classified `done`) no longer resolves the session's owner asks; only an explicit done / running / waiting STATUS does, pinned by a stall test · area: manager

- **An owner ask also resolves when its session's branch is merged (bug-71b3ff6a, second trigger)** — a merged / deployed integration request of the session closes its older open owner asks (`reason: ... its branch <b> was merged`), so an item the session already acted on is never listed again · area: manager

- **A stale owner item resolves itself (bug-71b3ff6a)** — the owner answers in the session pane and nothing told the ledger, so asks stayed "waiting for you" for hours after the session built, merged and closed. A later stop whose STATUS is done / running / waiting (not on the owner) now appends `state: resolved` (reason, at, `via: session-moved-on`) to `manager-owner-asks.jsonl`; the open view, `manager-status-scan.sh` and the stale list drop it · area: manager

- **Pictures and HTML mockups open from the reader, on any device** — a file an agent sent (SendUserFile) or a picture / page path it wrote showed as a bare name, and the file sat on codebox. The reader now shows pictures inline (click: full size in a new tab) and gives pages, PDFs and videos an "open ↗" link; the dashboard serves them at `/files/<path>` (media types only, home folder and scratchpads only, no dot folder except uploads, HTML sandboxed). Shell cache `ghosty-shell-v181` · area: dashboard

- **Pasted check messages show as the AI's, not yours** — the session file stores a long prompt as `<pasted_content id="…">…`, so the start of the text never matched the logged send and the done check's "Status check:" messages showed in the owner's blue.
